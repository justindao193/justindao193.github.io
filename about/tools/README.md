# Carry-on icon assets

These icons identify tools Justin uses; they do not imply endorsement. SVGs are served locally with visible text labels. Keep brand colors and proportions intact.

- Python, JavaScript, HTML5, CSS3, Tableau, Figma, GitHub, SAP, Claude, OpenAI: SVG Logos collection by Gil Barbara, via Iconify (`https://github.com/iconify/icon-sets/blob/master/json/logos.json`, CC0 collection).
- Power BI, Power Automate: Microsoft PowerBI-Icons (`https://github.com/microsoft/PowerBI-Icons/tree/main/SVG`). Original files: Power-BI.svg, Power-Automate-Colored.svg. Brand marks remain their owners' trademarks.
- Excel and SharePoint: Microsoft Office Fabric CDN product icons (`https://res.cdn.office.net/files/fabric-cdn-prod_20230815.002/assets/brand-icons/product/svg/`, excel_48x1.svg and sharepoint_48x1.svg).
- Dynamics 365: Simple Icons, via Iconify (`https://github.com/iconify/icon-sets/blob/master/json/simple-icons.json`, CC0).
- SQL: VSCode Icons file-type-sql (`https://github.com/vscode-icons/vscode-icons`, MIT). SQL is a language, so this is a language/file icon rather than a vendor logo.
- Codex uses the OpenAI brand mark with its product name alongside it.

Downloaded 2026-10-31. No third-party runtime icon requests or icon-font dependency.
